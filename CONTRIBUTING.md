# Contributing

This repository is a personal fork of [microsoft/SynapseML](https://github.com/microsoft/SynapseML), trimmed down to the LightGBM module. It is not open to external contributions: issues and pull requests are not accepted. Please report bugs and send contributions to the upstream project instead.

このリポジトリは microsoft/SynapseML を LightGBM モジュールに絞った個人用フォークです。外部からの Issue / Pull Request は受け付けていません。バグ報告や貢献は upstream へお願いします。
